# Изображения лендинга

Клади файлы **сюда**: `public/images/`  
В коде они доступны по URL **`/images/имя-файла`**.

## Hero (первый экран)

- **`hero-bg.webp`** — фон блока Hero (`cover`, центр). Рекомендуй горизонтальный кадр **от ~1920×900** и выше.

Если нужен другой формат — в `src/landing/sections/HeroSection.module.css` в `.bg` поменяй `url('/images/hero-bg.webp')`.

## Слайдер «до / после»

- **`problem-before.webp`** — **«до»** (слева от ползунка).
- **`problem-after.webp`** — **«после»** (справа от ползунка).

Желательно одинаковый кадр и разрешение у обоих кадров.

## Галерея «в реальных подъездах»

- `1.webp` … `4.webp` — кадры карусели по порядку (см. `GallerySection.tsx`).

## Иконки соцсетей (уже в репо)

- `social-tg.png`, `social-max.png`, `social-wa.png`
